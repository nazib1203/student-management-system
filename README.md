# Student Management System 🎓

A RESTful backend application built using Spring Boot 3, Spring Data JPA, and MySQL.

## 🛠️ Tech Stack
- **Language:** Java 17+
- **Framework:** Spring Boot 3
- **ORM:** Spring Data JPA (Hibernate)
- **Database:** MySQL
- **Tooling:** Maven/Gradle, Lombok, Postman

## ✨ Key Features
- **Student CRUD Operations:** Full backend lifecycle management.
- **Search:** Dynamic student search by name.
- **Validation:** Request body validation using `@Valid`.
- **Exception Handling:** Global exception handling using `@ControllerAdvice`.
- **DTO Mapping:** Clean layer separation between Controller, Service, and Entity.
- **Pagination & Sorting:** Built-in dynamic database pagination and sorting.
- **Logging:** Application logging for monitoring endpoints.
